# Project Development Guidelines

## Before Starting
- Inspect the existing project structure.
- Read README.md and understand the architecture.
- Review existing code before making changes.
- Do not unnecessarily rewrite existing modules.

## Coding Standards
- Follow the existing naming conventions.
- Write clean, modular and maintainable code.
- Avoid duplicate code.
- Handle errors appropriately.

## Git Workflow
- Never directly modify main.
- Create a feature branch for new tasks.
- Keep commits focused and meaningful.
- Never delete existing branches without permission.
- Never force-push without permission.

## Testing
- Run relevant tests after implementation.
- Fix errors introduced by your changes.
- Report tests that could not be executed.

## Reporting
- Explain files created or modified.
- Summarize implementation.
- Report test results.
- Mention remaining issues.
